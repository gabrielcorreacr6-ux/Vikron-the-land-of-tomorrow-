# Vikron: The Land of Tomorrow

RPG 3D para navegador (Three.js r128), otimizado para celular.

## Arquivos (todos na raiz do repositório)
- `index.html` – o jogo inteiro
- `agua.jpg` – skin do oceano
- `grama.jpg` – skin do terreno
- `areia.jpg` – skin da praia

Os nomes são sensíveis a maiúsculas/minúsculas no GitHub Pages.

## Como jogar
Joystick à esquerda para andar, botão amarelo para coletar. No PC: WASD/setas e E/espaço.
Cair na água = afogamento.
